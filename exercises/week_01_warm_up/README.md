# Week 1 — Experimental Repeatability

## Objectives

- Create a project environment,
- Understand the pseudorandom number generator,
- Learn to use the `seed` parameter,
- Separate the code from the notebook,
- Write the first automated tests,
- Recreate the project in a new environment.

## Passing Criteria

- The project has a clear structure,
- Dependencies can be installed with a single command,
- The function generates a sample of a given size,
- The same seed produces the same result,
- Different seeds produce different results,
- Tests pass correctly,
- The project can be recreated after removing the environment.
