# Machine Learning Finance Roadmap

This repository documents my 36-week Machine Learning curriculum, with a focus on applications in finance, banking, and economics.

## Main Goals

- Mastering the statistics and mathematics needed for ML,
- Building repeatable experiments,
- Creating regression and classification models,
- Time series analysis,
- Credit risk modeling,
- Implementing and monitoring models.

## Repository Structure

- `data/` — source and processed data,
- `notebooks/` — analysis and visualizations,
- `src/` — reusable code,
- `tests/` — automated tests,
- `reports/` — results and graphs,
- `projects/` — larger portfolio projects.
